# Страница показа

`index.html` — одна страница с быстрым доступом к экранам POSitive Loyalty на демо-кафе
«POSitive Demo»: владелец, касса, гость, QR для вступления и сценарий показа на пять минут.
Ничего не скачивать: все ссылки ведут в боевые веб-приложения.

Демо-кафе и его гостей заводит `pnpm demo:venue` (`prisma/demo-venue.ts`). Id заведения,
телефоны и id демо-гостей на странице — оттуда же: поменялись там — поменять здесь.

Паролей и почты владельца на странице нет и быть не должно: она открыта по ссылке.

## Выложить

Cloudflare Pages, проект `positive-demo`, мимо GitHub — как пульт:

```bash
wrangler pages deploy tools/showcase --project-name=positive-demo --branch main
```
